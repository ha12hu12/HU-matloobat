# HU — توصيل وطلبات (الفرونت اند)

فرونت اند React لمشروع HU-matloobat.

## تشغيله على جهازك

1. تأكد إن الباك اند شغّال (`uvicorn app.main:app --reload`).
2. ثبّت الاعتماديات (أول مرة بس):
   ```
   npm install
   ```
3. انسخ ملف الإعدادات:
   ```
   cp .env.example .env
   ```
   (على ويندوز: انسخ `.env.example` والصقه باسم `.env`)
4. شغّل السيرفر المحلي:
   ```
   npm run dev
   ```
5. افتح الرابط اللي يطلع لك بالـ terminal (عادة `http://localhost:5173`).

## النشر (زي 2h-store)

1. ارفع هذا المجلد لمستودع GitHub منفصل (أو مجلد `frontend/` بجانب `backend/` بنفس المستودع).
2. روح لـ [vercel.com](https://vercel.com)، اربط حسابك بـ GitHub، واستورد المشروع.
3. Vercel يكتشف تلقائيًا إنه مشروع Vite — ما تحتاج تغيّر إعدادات البناء.
4. أضف متغير بيئة بإعدادات المشروع على Vercel:
   - الاسم: `VITE_API_URL`
   - القيمة: رابط الباك اند بعد نشره (Render مثلاً)
5. اضغط Deploy.

**مهم**: الباك اند نفسه لازم يكون منشور على منصة زي Render قبل هالخطوة (مو شغّال على جهازك بس)، وإلا التطبيق ما يقدر يتواصل معه من أي جهاز ثاني.
